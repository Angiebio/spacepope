Oracle has instituted a ban on AI-generated code contributions to OpenJDK, the open-source implementation of the Java Platform that Oracle stewards. The policy was reported by Hacker News on August 7, 2026, under the headline "Oracle bans AI-generated code from OpenJDK despite Ellison's claim Oracle isn't writing its own code."

The supplied material does not include the text of Oracle's policy, the reasoning offered for it, or the remarks attributed to Oracle chairman Larry Ellison beyond the headline's phrasing. No further quotation, statement, or elaboration from Oracle, Ellison, or the OpenJDK project is available in the source material provided to this desk.

OpenJDK is a widely used open-source project, and Oracle's stewardship of it gives the company significant influence over contribution standards for the Java ecosystem. A restriction on AI-generated code from a project of this scale would affect contributors and downstream users of Java tooling, though the scope, mechanism, and enforcement of the ban are not detailed in the material at hand.
