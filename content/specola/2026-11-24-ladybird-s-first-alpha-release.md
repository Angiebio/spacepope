Ladybird, the independent browser project, has issued its first alpha release, according to a report by Simon Willison published November 23 on his website.

Willison describes Ladybird as an unusually ambitious undertaking: a browser built with its own implementations of core components, including HTML parsing, a CSS engine, layout, JavaScript, and WebAssembly. The project does rely on a handful of external libraries for specific tasks. Willison's summary names HarfBuzz for text shaping, Skia for 2D graphics, ffmpeg for video handling, and SQLite for database functions.

The source material available does not extend beyond this description of the architecture and the announcement of the alpha milestone itself. No release notes, version numbers, platform availability, or performance benchmarks are included in the cited summary.

Willison's framing emphasizes the rarity of the effort rather than its outcome. Building a browser from scratch, replicating the parsing, rendering, and scripting layers that underpin the modern web, is characterized as a substantial engineering undertaking, particularly for a project reaching this stage in 2026, well after the field's major incumbents were established.
