Google has begun early access rollout of a new Model Context Protocol server for Google Home, according to TechCrunch AI. The server allows AI agents, including Claude and ChatGPT, to interact with connected home devices through natural language commands rather than dedicated app controls.

Per the report, the integration permits these agents to issue control commands to smart home hardware, review summaries generated from camera footage, and query recent smart home activity logs. TechCrunch AI describes the move as extending Google Home's reach beyond its own assistant, opening the platform to third-party AI systems built by competing companies.

The Model Context Protocol, cited in the report as the underlying standard, functions as a common interface allowing various AI agents to query and command external services without custom-built integrations for each one. Google's adoption of this protocol for its home ecosystem places smart home control within the same interoperable framework already used for other AI agent tasks.

The report frames the release as early access, indicating a limited initial rollout rather than a full public launch. No specific timeline for broader availability, nor details on device compatibility beyond the general Google Home ecosystem, are included in the cited material. TechCrunch AI's coverage notes the development as part of a wider industry pattern of extending agent capabilities into physical, internet-connected environments through standardized protocols.
