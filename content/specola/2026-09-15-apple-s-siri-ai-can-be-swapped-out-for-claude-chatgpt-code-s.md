Code discovered within Apple's operating system builds indicates that Siri's underlying AI backend can be swapped for third-party large language models, including Anthropic's Claude and OpenAI's ChatGPT. The finding, reported by MacRumors on September 14, 2026, and circulated via Hacker News, stems from analysis of internal code rather than an official Apple announcement.

The report does not specify a public release date or confirm which models, beyond Claude and ChatGPT, might be supported. It is likewise silent on whether the modular arrangement would extend to all Siri functions or only a subset, and on what commercial terms might govern such a swap between Apple and outside AI developers.

No statement from Apple, Anthropic, or OpenAI accompanies the code findings as reported. The story rests on the discovery itself, described as evidence within the operating system's code rather than a confirmed feature.

Observers cited in the report frame the discovery as a signal that Apple may be moving toward a more modular architecture for its voice assistant, one in which the underlying model answering a user's query need not be Apple's own. The report stops short of characterizing this as a finished product decision, describing it instead as a capability found present in code.

Further confirmation from Apple has not been reported at this time.
